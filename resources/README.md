# Resources that could help!!!
## Setup
1. Creating a Virtual Enviroment
- creating venv is important so the dependencies doesnt interset.
    ```
    python -m venv venv
    ```
after creating a new vevn remember to close the terminal and open a new one
2. Active the venv
- MacOS or Linux:
    ```
    source vevn/bin/active
    ```
- windows:
    ``` 
    venv\Scripts\active
    ```
3. Install the Dependencies
- upgrade pip
    ```
    python -m pip install --upgrade pip
    ```

    ```
    pip install -r requiremenets.txt
    ```
- you can check you installed it correctly, using:
    ```
    pip list
    ```

4. If done with the work, deactive the venv
    ```
    deactivate
    ```
