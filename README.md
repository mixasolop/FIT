# Music2Nodes – Audio to Notes (Team Project)

Music2Nodes is a team project created to help beginner musicians.
The user uploads an audio recording of an instrument and receives
the musical notes needed to reproduce the sound.

## Project idea
The system processes audio input, removes noise using an AI-trained model
and analyzes frequencies to determine musical notes.

## My contribution
- Frontend development
- UI logic and user interaction
- Integration of audio upload and result display
- Linking the AI model response to the frontend output

## AI part (high level)
- Pre-trained model used for audio denoising
- Frequency analysis performed on cleaned audio
- Frequencies mapped to musical notes
